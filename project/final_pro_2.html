Security Web & App Vulnerability Analysis & SIEM Defense

취약한 가상 병원 예약 플랫폼 구축 및 공격 시나리오 기반 통합 보안 관제 실습

OWASP Top 10 WAF (ModSecurity) IDS/IPS (Suricata) SIEM (ELK Stack) Wazuh

01. Project Overview

본 프로젝트는 병원 예약 및 관리 기능을 제공하는 가상 의료 플랫폼을 대상으로 웹 및 모바일 환경의 보안 가용성을 검증하기 위해 기행되었습니다. 단순한 공격 실습에 그치지 않고, IDS/IPS/SIEM 시스템을 직접 구축하여 공격 흐름을 파악하고, WAF 정책 수립 및 로그 분석을 통해 실무적인 침투 테스트와 방어 역량을 확보하는 것을 목표로 하였습니다.

나의 주요 역할

인프라 구축

  • 모바일 앱 서버 백엔드(Node.js/Nginx) 및 DB(MariaDB) 연동 환경 구축
  • Suricata(IDS/IPS) 설치 및 네트워크 미러링 환경 구성
  • WAF(ModSecurity) 도입 및 보안 정책 적용

분석 및 대응

  • OWASP Top 10 기반 웹 취약점 2종, 모바일 취약점 1종 분석
  • Filebeat를 활용한 보안 이벤트 로그 중앙 수집 (ELK Stack)
  • 공격 탐지를 위한 Suricata Custom Rule 및 WAF 차단 정책 작성

03. Web Vulnerability Walkthrough

직접 구축한 가상 병원 예약 플랫폼을 대상으로 수행한 웹 취약점 진단 및 대응 사례입니다.

1 / 3
[Phase 1] 취약점 탐색 및 진단

ZAP 및 수동 점검을 통해 예약 게시판 내 XSS 및 SQL Injection 포인트 식별. 병원 관리 페이지의 비인가 접근 가능성 확인.

[Phase 2] 공격 시나리오 재현 및 탐지

식별된 취약점을 이용해 환자 정보 탈취 공격 수행. Suricata에서 해당 페이로드 탐지 및 Kibana 대시보드 실시간 로그 유입 확인.

[Phase 3] 대응방안 적용 및 검증

ModSecurity 화이트리스트 기반 필터링 적용 및 PHP 소스 코드 내 prepared statement 적용을 통해 취약점 원천 차단 완료.

❮ ❯

04. Mobile Vulnerability Walkthrough

모바일 앱 패키지 분석 및 API 서버 취약점 분석을 통한 보안 강화 과정입니다.

1 / 3
[Phase 1] 모바일 취약점 점검

Android 패키지 디컴파일 및 API 통신 구간 가로채기를 통한 민감 데이터 노출(Insecure Data Storage) 분석.

[Phase 2] API 서버 공격 및 로그 분석

변조된 API 요청을 통한 타인 예약 내역 조회 공격 수행. Suricata IPS 모드에서 비정상적인 HTTP 패턴 차단 및 로그 집계.

[Phase 3] 대응 전략 및 대시보드 개선

Nginx 보안 헤더 설정 및 API 토큰 검증 로직 강화. SIEM 가시성 확보를 위해 Kibana 대시보드 시각화 차트 고도화.

❮ ❯

05. Project Results & Insights

진단 및 분석 결과

  • 핵심 웹 취약점(OWASP Top 10) 8건 식별 및 조치
  • 모바일 API 및 바이너리 취약점 3건 식별
  • 공격 시나리오별 탐지 성공률 90% 이상 달성

보안 구축 핵심 성과

  • 웹/모바일 통합 공격 탐지 룰(Custom Rule) 적용
  • ModSecurity를 이용한 실시간 공격 차단 체계 마련
  • ELK 기반 SIEM 환경 구축을 통한 통합 로그 가시성 확보

향후 개선사항

  • 탐지 오탐율(False Positive) 감소를 위한 정책 정교화
  • 신규 공격 패턴(0-Day) 대응을 위한 룰셋 최신화
  • Kibana 대시보드 UI 개선 및 자동 알림 시스템 연동

이 경험을 통해 보안은 단순히 공격을 차단하는 것이 아니라, 시스템 구조의 깊은 이해를 바탕으로 탐지, 대응, 운영이 유기적으로 연결되어야 한다는 점을 깨달았습니다. 안정성과 운영 효율을 모두 고려한 보안 설계를 수행하는 엔지니어로 성장하겠습니다.
